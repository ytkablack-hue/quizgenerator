# TestHelper для Android

TestHelper сохраняет прежний Android package ID `kz.quizgenerator`. Офлайн доступны ручное создание, импорт готовых вопросов из UTF-8 TXT, текстового DOCX и JSON, просмотр и редактирование вопросов, карточки, режимы тестирования, история результатов и план подготовки к экзамену. Уже сохранённые тесты и карточки ИИ тоже открываются офлайн.

## Сборка

Из каталога `android` с JDK 17 и Android SDK Platform 35:

```powershell
.\gradlew.bat :app:test :app:lint :app:assembleDebug
```

APK — `app/build/outputs/apk/debug/app-debug.apk`. Android принимает обновление существующей установки только с тем же package ID и сертификатом подписи. Сохраняйте свой debug keystore вне Git, если обновляете отладочные версии поверх существующих.

## ИИ

Запустите [локальный backend](../backend/README.md) на компьютере. В Android укажите базовый адрес backend и, если он настроен, отдельный код доступа к нему. Для физического устройства нужен доступный из доверенной сети HTTPS-адрес с доверенным сертификатом. Debug-вариант также поддерживает HTTP только для локальных адресов тестирования. Ключ OpenAI задаётся исключительно в среде процесса backend.

В разделе «Создать с ИИ» можно проверить статус backend, создать тест или карточки по теме либо по TXT/DOCX, а также разобрать последний тест с ошибками. Приложение отправляет учебный материал только при запуске запроса пользователем. Проверьте результат перед сохранением. Локальный план повторения работает независимо от ИИ.

## Проверка на устройстве

- Обновление поверх ранее установленного APK с тем же сертификатом, сохранение тестов и правок.
- Создание теста и карточек, импорт TXT/DOCX/JSON, предпросмотр и редактирование.
- Поворот и сворачивание во время теста, ручное завершение и срабатывание таймера.
- Повторный запуск с выключенным интернетом, доступ к библиотеке, результатам и плану.
- Настроенный HTTPS-backend, генерация с действующим ключом и повторное открытие сохранённых материалов офлайн.


## Beta 0.3.0

В интерфейсе четыре вкладки: «Главная», «Создать», «Библиотека» и «Подготовка». Меню настроек открывается из верхней панели. Светлая, тёмная и системная темы меняются в настройках. Ручной ввод, документы и вопросы ИИ открываются в одном редакторе, а новый тест появляется в библиотеке после явного сохранения.

Потоковый импорт Word сохраняет входной ZIP во временный файл и читает только `word/document.xml`. Архив проверяется по центральному каталогу, размеру и CRC. Индикатор учитывает копирование и чтение XML. Отмена очищает временный файл. Ограничения офлайн-импорта — 64 МиБ для DOCX, 128 МиБ для XML, 8 млн символов текста и 500 вопросов. Если документ превышает лимит, разделите его на части. Лимит свободного материала для ИИ остаётся 12 тыс. символов.

Регрессионные тесты создают DOCX с распакованным XML около 4 и 20 МиБ и проверяют найденные вопросы, ключ ответов, завершение прогресса и очистку временных файлов. Отдельные прогоны проверяют отмену и превышение размера архива. Это синтетические тесты JVM. Замер памяти и времени на телефоне сюда не входит.

### Обновление и ручная проверка

1. Скачайте APK с GitHub Releases и установите поверх 0.2.0. Android примет обновление при совпадающем сертификате. Если система сообщит о конфликте подписи, оставьте текущую установку, чтобы сохранить её локальные данные.
2. На узком и широком экране, в обеих ориентациях, с повышенным размером шрифта и с клавиатурой проверьте вкладки, формы, календарь и основные кнопки.
3. Импортируйте большой реальный DOCX, отмените повторный импорт и убедитесь, что черновик не попал в библиотеку. Откройте TXT и JSON, тест из ИИ, отредактируйте вопрос и сохраните.
4. Начните тест, выберите ответы, поверните экран и убедитесь, что ответы и время сохранились. Пройдите ручное и автоматическое завершение, повторите тест и проверьте историю.
5. После обновления проверьте ранее сохранённые материалы, карточки, результаты и экзамены. Повторите проверку без интернета и в тёмной теме.
