## Реализовано в Android

Production HTTPS URL без общего секрета; вход/регистрация Email/Password через Firebase REST; подтверждение email, восстановление пароля, профиль, выход, удаление аккаунта через Worker. Пароли не сохраняются; токены шифруются Android Keystore в noBackupFilesDir. Авторизация требуется только для ИИ. Локальные тесты/карточки/история не требуют сети. Старый общий код удаляется из settings при чтении/сохранении без изменения существующей схемы учебных данных.

Главная с одной основной задачей создания; общий сценарий документа/фото/текста с общим редактором. Подготовлены распознавание PDF/JPEG/PNG через Gemini, редактирование распознанного текста, настройка числа вопросов/сложности и проверка ответов. Для TXT/Word/JSON используется существующий локальный импорт. Раздел подготовки объединяет существующие тесты, карточки, ошибки, историю, реальные показатели и экзамены. Добавлено повторение вопросов с ошибками, переход к объяснению выбранной попытки с ИИ и генерации карточек.

Тема светлая/тёмная/системная сохраняется и применяется сразу; скорректированы системные панели. Таймер: без ограничения, 5/10/15/20/30/45/60 минут, своё время 1–180 минут, предупреждение последней минуты. Сохраняются снимок теста, ответы, индекс и срок; внутри одного запуска ОС используется elapsedRealtime, после перезагрузки — сохранённое wall-clock ограничение. При ошибке сохранения результата попытка не объявляется успешно сохранённой. Миграции локального файла и снимка покрыты unit-тестами, но обновление на реальном устройстве ещё не проверено.

Проверка RSA-подписи Firebase, exp/iat/auth_time/aud/iss/sub/provider, подтверждённой почты и актуальности аккаунта; постоянные пользовательские/IP/общие квоты в SQLite Durable Object; ограничение файлов и JSON, проверка результатов Gemini, защита от повторного резервирования запроса. ## Остаточные риски

Два внешних хранилища не дают общей транзакции удаления: сбой между Firebase и квотой требует поддержки или истечения TTL. Снятие счётчиков из активного хранилища не гарантирует физическое стирание провайдерских PITR/логов. Следует уточнить retention и использование данных бесплатным Gemini у владельца. Пароли/документы не логируются кодом Worker; условия платформенных логов проверяются отдельно. Инструкции промпта/валидация снижают риск prompt injection, но правильность учебных ответов не гарантируют. Аппаратная защита Keystore не защищает полностью скомпрометированное устройство. Legacy admin-код сохранён на сервере ради совместимости и требует ограниченного распространения.
