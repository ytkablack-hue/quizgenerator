# TestHelper — проект политики конфиденциальности

Дата проверки реализации: 22 ноября 2026 года. Черновик, не опубликован. До публикации владелец должен заполнить юридическое имя/контакт, страны распространения, возрастную аудиторию, сроки обработки обращений и публичный URL. Не выдавать этот текст за утверждённую юридическую политику.

## Локальные функции

Тесты, выбранные ответы, история попыток, карточки, экзамены и настройки хранятся в закрытом каталоге приложения. При первом запуске требуется вход Google или Email/Password. После первого входа локальные функции доступны без сети; проверка действительности Firebase ID Token требуется для облачного ИИ. Автоматическая облачная синхронизация документов не реализована. Автоматическое резервное копирование Android отключено; ручной ZIP-экспорт текущей библиотеки доступен через системный выбор файла и исключает токены и данные других аккаунтов; сохранность после удаления приложения не обещается. Перед удалением приложения пользователь должен отдельно сохранить нужные материалы.

## Аккаунт и ИИ (подготовленная новая интеграция)

Firebase Authentication обрабатывает почту, данные аутентификации и выбранное имя. Google-вход использует Android Credential Manager; приложение обменивает Google ID Token на Firebase-сессию и не сохраняет Google-токен. Приложение не хранит пароль; токены сессии шифруются ключом Android Keystore вне резервных копий. При выходе локальная сессия удаляется, учебные данные остаются. Библиотеки разделены по хешу Firebase UID. Владелец прежней библиотеки подтверждается явно, файлы не перемещаются; другой UID получает отдельное хранилище. После удаления аккаунта новый UID не получает доступ к старой библиотеке: заранее сохраните ручную копию.

Только по действию пользователя тема, учебный текст, выбранный PDF/фото или ошибки отправляются через Cloudflare Worker в Gemini. Экран предупреждает об этой передаче до кнопки отправки. Для ИИ нельзя загружать чужие персональные данные, секреты и материалы без права использования. Ответы ИИ могут содержать ошибки и требуют проверки. Локальный OCR PDF/JPG/PNG работает на устройстве без отправки документа. Облачное распознавание Gemini требует интернет, подтверждённый аккаунт и явное действие пользователя; автоматической отправки при локальной ошибке нет. Языковые данные OCR являются общими ресурсами приложения, не пользовательскими документами.

Worker не сохраняет документы и ответы модели в собственной базе. Для ограничения использования подготовлены короткоживущие счётчики по хешам UID и IP; они удаляются из активного хранилища после смены дня (с периодом обслуживания около минуты). При удалении аккаунта удаляются связанные с UID счётчики, IP/общие агрегаты сохраняют короткий TTL. Cloudflare SQLite PITR может хранить историю до 30 дней: логическое удаление не означает немедленное физическое стирание резервных копий провайдера. Это псевдонимизация, не доказанная анонимизация. Cloudflare, Firebase и Gemini могут обрабатывать технические метаданные и сохранять данные по собственным условиям.

Владелец обязан проверить условия конкретного тарифа Gemini, включая использование введённых материалов для улучшения продуктов Google на бесплатном API, фактические сроки хранения и географию обработки. Заявления «данные нигде не сохраняются» или «не используются для обучения» сейчас недопустимы.

## Удаление

Подготовлено: Настройки → Личный кабинет → Удалить аккаунт; веб-форма на /delete-account существующего Worker после развёртывания. Удаляется аккаунт Firebase, доступ к ИИ прекращается; подтверждение от Firebase требуется фактически проверить. История/тесты на устройстве остаются. Для удаления отдельных локальных тестов и карточек есть соответствующие действия; полное удаление локальных данных возможно через системные настройки/удаление приложения. Условия остаточного хранения у провайдеров уточняет владелец.
