# TestHelper 0.7.0 Beta — ограничения и приёмка

## Что проверить на настоящем телефоне

Автоматические JVM/HTTP-тесты и компиляция не заменяют Android UI. Эмулятор/ADB не запускались; в установленном SDK нет layoutlib для поддерживаемого headless-рендера Compose.

1. Установить APK поверх 0.6.0 без удаления приложения; предварительно экспортировать важные данные. Проверить старые тесты, карточки, историю, выбранный материал, тему и активную попытку. Совместимость JSON и защита отменённых снимков проверяются автоматически; реальное обновление Android — нет.
2. Google Credential Manager/Email: вход, отмена, связывание одного UID, письмо/сброс/ошибки, выход/удаление, повторный офлайн-вход, два аккаунта и Keystore. Firebase/Worker не перенастраивались; новый реальный Google-вход на телефоне в этой задаче не проверен.
3. По теме без документа (в том числе внутри набора с файлами): тема → количество 1/25 → подтверждение; убедиться, что предпросмотр material пуст. Затем текст/документ/тема, навигация/поворот/перезапуск. При холодной загрузке дождаться восстановления настроек; выбор режима должен сохраняться.
4. По отдельному согласию на передачу материала выполнить один запрос из нового UI к Gemini. Локальный HTTP-тест проверяет wire-контракт, JWT-заголовок, формат и 429; настоящую генерацию Gemini он не выполняет. Production в этой задаче не вызывался и не изменялся.
5. Настоящие университетские TXT/DOCX/PDF/JPG/PNG/JSON: русский/казахский/английский, списки/таблицы, текстовые PDF/OCR разных API, EXIF, плохие/пустые сканы, отмена и повторное открытие. Нативный Tesseract/PdfRenderer на компьютере не запускались. На 800–1500 вопросах измерить время, RAM и нагрев. Тестовые документы генерируются, реальных учебных файлов в задаче нет.
6. Семь нативных экранов сравнить с Stitch: 360dp, увеличенный шрифт (1.3/2.0), светлая/тёмная/системная тема, длинные заголовки, пустая/большая библиотека, клавиатура, статус-бар и жестовая полоса. Код использует переносы/FlowRow/scroll/maxWidth/48dp, но отсутствие клиппинга и точность совпадения макета ещё не доказаны снимками Android.
7. Обучение/экзамен: количество локального банка, таймер, shuffle/multi-answer, проверка ответа только в обучении, отсутствие любых подсказок в экзамене; закладки/переход/повтор; сворачивание/завершение таймера/восстановление. Проверить все результаты, время, неизвестные ключи, повтор ошибок и карточки из достоверных ошибок.

## Явные ограничения

- Оригинал до 64 МиБ, текст до 8 млн символов; ограничения распаковки ZIP/XML/PDF/OCR и 5000 вопросов/64 вариантов остаются. Материал не ограничен локальными 12 000 символов. Нестандартные Word styles/неоднозначная структура требуют просмотра исходного фрагмента.
- Сервер: до 25 вопросов/карточек за запрос, 12 000 символов материала и 65 536 UTF-8 байт JSON. Полный документ не отправляется автоматически. Неполный/слишком большой вопрос требует ручного диапазона и согласия. Счётчик успешных частей не доказывает правильность или полноту ответа ИИ. После изменения параметров это отдельная серия.
- OCR-пустые страницы при прикреплении PDF явно перечисляются, оригинал сохранён целиком; полностью пустой документ не принимается. Прямой импорт готовых вопросов остаётся строгим. Отмена нативной операции может дождаться завершения текущей единицы распознавания.
- Сохранённые материалы/черновик/режим/страница восстанавливаются; незавершённый сетевой ответ/несохранённые AI-карточки после уничтожения процесса не гарантированы. Заметку нужно сохранить явно. Отмена клиента не гарантирует отмену серверной квоты.
- Закладки хранятся в активной попытке, доступны при прохождении и на текущем экране результатов. Отдельного глобального каталога закладок и их истории между завершёнными попытками нет.
- Длительность старых попыток не выдумывается: «Не измерено». Новые используют монотонные часы, после перезагрузки — допустимый wall-clock fallback; при переводе часов назад длительность может остаться неизвестной. Таймер ограничивает учитываемое время своей границей.
- Открепление/архив не удаляют оригиналы. ZIP экспортирует реальные данные; отдельного UI восстановления всего ZIP нет. Сгенерированные предположения не становятся подтверждёнными ключами автоматически.
- Локальная LLM не установлена. Новые провайдеры/смена Gemini/серверный кэш/миграция квот — будущий отдельный этап, см. docs/ai-next-stage.md. Модели и тяжёлые runtime без разрешения не скачивать. Нет фиктивных прогнозов оценки, антибота, дневной цели или AI-аналитики.

Перед публичным релизом нужны ручная приёмка, утверждение privacy/terms/контакта владельцем и проверка лицензий. App Check/Play Integrity не добавлялись; прежние Firebase JWT/SQLite-квоты сохранены. Релиз 0.6.0 остаётся доступным, 0.7.0 в этой задаче публиковать не разрешено. Точные результаты финальной сборки — docs/testhelper-0.7.0-verification.md.
