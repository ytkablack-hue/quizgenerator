# Остаток после реализации лекций и пакетных заданий

Утверждённая Home Beta f69d86f сохранена без изменений; повторное утверждение главной не является блокером. Новый этап реализован локально, production не менялся. Актуальные проверки/APK: docs/verification-study-batch.md; безопасный серверный этап: docs/study-batch-rollout.md.

## Требуется отдельное разрешение production

- В существующий testhelper-ai включить валидированные /api/v1/ai/lectures, /api/v1/ai/answers и capabilities. Сохранить действующий deployment для rollback, secrets/Firebase/SQLite/модель/квоты/бесплатный тариф. Без разрешения не выполнять deploy.
- Затем реальный Firebase JWT → Worker → Gemini: небольшая лекция, две исходные задачи, неизвестный и множественный ключ, сохранение/чтение в Android. Все выполненные в текущей задаче проверки контрактов — локальные, не реальная генерация.
- Новый публичный Release не разрешён. APK пока локальный, в GitHub только исходники, тесты и документация.

## Проверить на настоящем Android

1. Перед обновлением экспортировать важные данные. Установить поверх Home Beta без удаления: прежние тесты/карточки/история/тема/активная попытка и новый код10. Формат старых JSON/изоляция/сохранность покрыты JVM-регрессиями, фактическое обновление Android не проверено.
2. Новые формы/лекции/задания:360dp,1.3x, длинные русские названия, светлая/тёмная/системная тема, клавиатура/системные отступы, TalkBack. Подтверждённого Compose-render/снимков нет; отсутствие клиппинга не доказано на устройстве.
3. Фоновая серия: запрос разрешения уведомлений/отказ, запуск, сворачивание, пауза из уведомления, отмена во время HTTP, офлайн/429/потеря ответа, перезапуск/force-stop, энергосбережение Android8–16 и два аккаунта. Выполненные партии не должны повторяться. После force-stop нужен ручной запуск; никакого обещания непрерывной фоновой сети.
4. TXT/DOCX/PDF/изображения реальных документов:200/500 вопросов, таблицы/автонумерация, кириллица/казахский, пустые OCR-страницы, нативные Tesseract/PdfRenderer, исправление проблемного вопроса, оригинал. Автоматические документы синтетические; нативный OCR на компьютере не выполнялся. Замерить RAM/время/нагрев на больших файлах.
5. Лекция: CRUD/источник/офлайн, выход во время правки, создание теста/карточек с явным подтверждением; отредактированная частичная лекция сохраняет пользовательские правки и не перезаписывается завершённым заданием. Полный результат остаётся в задании; автоматического слияния с ручными правками нет.
6. Регрессия Firebase Google/Email/Keystore, выхода/удаления и офлайн-сессии; обучение/экзамен/таймер/закладки/результаты/экспорт. Моки авторизации не подтверждают реальный Google-вход или доставку писем.

## Ограничения

Неоднозначные или чрезмерно длинные вопросы/контекст требуют ручной проверки; малый источник не повторяется многократно ради500 вопросов. Планы имеют ограничение JSON/памяти, исходник64МиБ/текст8млнсимволов/банк5000вопросов64варианта. Качество/фактическая правильность текста ИИ не гарантируются структурной валидацией. Все CLOUD_AI/UNKNOWN не участвуют в строгой оценке до ручного подтверждения. Квоты сохраняются;500 вопросов могут исчерпать дневной лимит. Локальная LLM не устанавливалась. Эмулятор/ADB/SDK/новые зависимости не использовались.
