# Локальный ИИ: подготовленная граница, не работающий движок

22.11.2026. AnswerInferenceProvider принимает только вопрос и все варианты без ключа/пояснения документа. Результат: набор индексов, краткое объяснение, uncertain, LOCAL_AI/CLOUD_AI, ревизия провайдера. Валидатор запрещает неправильные индексы/пустой уверенный результат/смену происхождения. Облачный вызов требует явного согласия до вызова провайдера. Отмена/ошибка не включает автоматический облачный fallback. Никакого production inference провайдера пока нет; тестовые адаптеры существуют только в unit tests.

InferenceSampleAdapter использует существующие SampleAnswerCheck/AnswerCache: неопределённые и несколько ответов не обосновывают правило первого варианта; нужно30независимых ответов и явное подтверждение. Применённое правило остаётся INFERRED и не влияет на строгую оценку. Из UI убрано применение первого варианта без проверки. Сейчас проверка30вопросов недоступна до подключения реального провайдера.
