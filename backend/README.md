# QuizGenerator Backend

Backend проекта на Python 3.11.9 и FastAPI.

AI Gateway предоставляет единый внутренний интерфейс для подключения внешних ИИ-систем через адаптеры.

На этапе создания каркаса реализации и зависимости не устанавливаются.

## Локальный API TestHelper

Модуль `testhelper_server.py` запускается на Python 3.11+ и использует стандартную библиотеку. Он слушает только `127.0.0.1`. Существующий каркас FastAPI остаётся отдельным.

```powershell
cd backend
python -B testhelper_server.py
```

Перед запуском передайте через среду процесса `OPENAI_API_KEY` и, при необходимости, `OPENAI_MODEL` (по умолчанию `gpt-4.1-mini`). Сервер не читает `.env` автоматически. Без ключа проверка доступности работает, а генерация возвращает HTTP 503. Программа не отправляет запрос OpenAI, пока клиент не запросит генерацию. Код доступа к собственному backend задаётся отдельно через `TESTHELPER_ACCESS_TOKEN`; при защищённом подключении введите этот код в Android-приложении. Ключ OpenAI вводится только на сервере. Порт задаёт `APP_PORT` (8000 по умолчанию).

Доступность — `GET /api/v1/health`, конфигурация ИИ — `GET /api/v1/ai/status`. Генерация — `POST /api/v1/ai/quizzes`, `/api/v1/ai/flashcards` и `/api/v1/ai/review`. Укажите тему или материал для теста и карточек. Для разбора передаётся текст уже сохранённых ошибок. Backend валидирует структурированный ответ и отклоняет неполный результат. Генерируемый контент следует проверить перед сохранением. Для физического телефона используйте доверенный, закрытый HTTPS-доступ к backend; модуль не настраивает публичный сервис.

Автоматическая проверка HTTP и ответов провайдера с заглушкой:

```powershell
python -B -m unittest discover -s tests -p test_testhelper_api.py -v
```
