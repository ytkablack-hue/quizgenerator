# Структура QuizGenerator

## Основные компоненты

- Android — клиентское приложение; `android/ui` — отдельная Compose-библиотека темы, компонентов и экранов.
- Backend — API и бизнес-логика.
- AI Gateway — независимый интерфейс подключения внешних ИИ-систем через адаптеры.
- Shared — общие спецификации API и AI-контрактов.
- Локальный профиль, тесты, карточки и прогресс обучения сохраняются на устройстве.
- Storage — файлы и база данных.
- Tests — системные и контрактные тесты.

## Архитектурный подход

Модульный монолит. Android взаимодействует с Backend через REST API.
AI Gateway является внутренней подсистемой Backend, а не отдельным микросервисом.
