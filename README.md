# QuizGenerator

Приложение для создания, редактирования и прохождения тестов с подключаемыми ИИ-моделями.

## Архитектура

- `android` — Android-клиент на Kotlin и Jetpack Compose.
- `backend` — серверное приложение на Python и FastAPI.
- `shared` — общие спецификации и схемы данных.
- `storage` — локальные данные приложения.
- `docs` — техническая документация.

## Android-интерфейс

Светлый интерфейс в стиле Steam вынесен в Android-библиотеку `:ui` и подключён к приложению. Он включает локальную регистрацию, библиотеку и редактор тестов, импорт, карточки и четырёхэтапное обучение по TXT/DOCX. Генерация тестов и карточек использует существующий AI backend. Профиль и учебный прогресс хранятся локально; backend пока не предоставляет аккаунты.

Сборка APK: из каталога `android` выполните `./gradlew :app:assembleDebug` с установленными JDK 17 и Android SDK 35.
