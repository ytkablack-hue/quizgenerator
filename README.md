# QuizGenerator

Приложение для создания, редактирования и прохождения тестов с подключаемыми ИИ-моделями.

## Архитектура

- `android` — Android-клиент на Kotlin и Jetpack Compose.
- `backend` — серверное приложение на Python и FastAPI.
- `shared` — общие спецификации и схемы данных.
- `storage` — локальные данные приложения.
- `docs` — техническая документация.

## Начало разработки

На текущем этапе создан только физический каркас проекта.
